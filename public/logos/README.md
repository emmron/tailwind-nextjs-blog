# Builder Logos

This directory contains the logos for the three Scott Park Group builder brands.

## Required Logo Files

Please add the following logo files to this directory:

### B1 Homes
- **Filename**: `b1-homes-logo.png` or `b1-homes-logo.svg`
- **Source**: https://b1homes.com.au/
- **Recommended size**: 300px width minimum
- **Format**: PNG or SVG (transparent background preferred)

### 101 Residential
- **Filename**: `101-residential-logo.png` or `101-residential-logo.svg`
- **Source**: https://www.101residential.com.au/
- **Recommended size**: 300px width minimum
- **Format**: PNG or SVG (transparent background preferred)

### Redink Homes
- **Filename**: `redink-homes-logo.png` or `redink-homes-logo.svg`
- **Source**: https://www.redinkhomes.com.au/
- **Recommended size**: 300px width minimum
- **Format**: PNG or SVG (transparent background preferred)

## How to Add Logos

1. Download the official logos from each builder's website
2. Save them in this `/public/logos/` directory with the filenames above
3. The website will automatically display them

## Current Status

⚠️ **Logo files are currently placeholders**

The website is currently using text-based logo placeholders. Replace these with actual logo image files using the filenames specified above.
